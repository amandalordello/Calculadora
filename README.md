# Calculadora Científica Web

Este projeto é uma calculadora científica responsiva e moderna desenvolvida com HTML, CSS e JavaScript. A interface foi projetada para ser intuitiva e funcional, permitindo que os usuários realizem operações matemáticas básicas e avançadas, como exponenciação, logaritmo, seno, cosseno, tangente e fatorial.

## Recursos
- Interface responsiva.
- Suporte a operações matemáticas avançadas.
- Exibição de histórico de cálculos.
- Feedback visual ao pressionar os botões.

## Estrutura do Projeto
- `index.html`: Estrutura principal da calculadora.
- `style.css`: Estilos visuais e responsividade.
- `script.js`: Lógica de funcionamento da calculadora.

## Funcionalidades
- **Básicas**:
  - Soma (+), subtração (-), multiplicação (*) e divisão (/).
  - Botão de apagar (⌫), limpar cálculo (C) e limpar display (AC).
  - Uso de números decimais.
 
- **Científicas**:
  - Porcentagem (%).
  - Expoente ao quadrado (x²) e raiz quadrada (√).
  - Logaritmo decimal (log) e natural (ln).
  - Funções trigonométricas: seno (sin), cosseno (cos), tangente (tan).
  - Número pi (π).
  - Cálculo de fatorial (x!).
  - Inversão de sinal (±).

## Instalação
Para visualizar a calculadora em sua máquina local, siga os passos abaixo:
1. Clone este repositório para o seu computador.
   ([https://github.com/amandalordello/Projeto-CIMATEC-Jr..git](https://github.com/amandalordello/Calculadora.git))
2. Abra o arquivo calculadora.html em seu navegador web preferido.
